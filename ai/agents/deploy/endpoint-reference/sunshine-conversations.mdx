## Endpoint-specific settings

### Advanced tab

#### Sunshine Conversations connection

| Parameter   | Description                                                                                                                                                                                                                     |
|-------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Authentication type | The method Cognigy uses to authenticate with your Sunshine Conversations app. Select **API key** or **OAuth**. With OAuth, the **Key ID** and **Secret** fields are hidden and the API version is fixed to `v2`. |
| OAuth Connection | The connection Cognigy uses to authenticate with OAuth. This parameter is required when you select **OAuth**. |
| API version | The Sunshine Conversations API version Cognigy uses to communicate with your app. Cognigy supports version `v1.1` and version `v2`. The version must match the one used to create the webhook in your Sunshine Conversations app. The default value is `v1.1`. |
| Key ID      | The key ID from your Sunshine Conversations app. The format is `app_XXXXXXXXXXXXXXXXXXXXXXXX`. The key ID is paired with the secret you provide.                                                                               |
| Secret      | The secret of your Sunshine Conversations app. This secret must match the key ID you entered earlier. The secret is masked. To view it, click the eye icon (**Show value**).                                                                |
| URI         | The URI where messages are sent to your Sunshine Conversations app. For example, `https://app.smooch.io`. This parameter is required. Don't include a trailing slash (`/`).                                                     |

## How to set up

<AccordionGroup>
  <Accordion title="1. Create a Sunshine Conversations endpoint">
    1. In the left-side menu of your project, go to **Deploy > Endpoints** and click **+ New endpoint**.
    2. In the **New endpoint** dialog, select the **Sunshine Conversations** endpoint type and click **Create endpoint**.
    3. On the **Setup** tab, configure the following:
        - **Endpoint name**: enter a unique name.
        - **Target type**: select the type of target.
        - **Target**: select an agent or flow from the list.
    4. Save changes. Then copy the URL from the **Endpoint URL** field.
  </Accordion>

  <Accordion title="2. Create a Sunshine Conversations app">
    1. Go to the [Sunshine Conversations Dashboard](https://app.smooch.io/) and log in with your Zendesk account.
    2. If you don't have a workspace yet, create one first. Otherwise, select your existing workspace. 
    3. Click **Create App**. Enter the name and description for your app. Click **Create**.
    4. Go to the **Channels** or **Integrations** tab. Add the messaging channels you want, for example, WhatsApp, Facebook Messenger, Slack. Follow the Sunshine Conversations instructions for each integration.
    5. Open the **Settings** tab of your app. Go to **API Keys** and click **+ Create new secret key**.
    6. Copy the **Key ID** and **Secret** for later use in the Cognigy Endpoint. Save changes.
  </Accordion>

  <Accordion title="3. Complete the endpoint configuration">
    1. In the Cognigy interface, open the Sunshine Conversations Endpoint you created.
    2. Go to the **Advanced** tab. In the **Sunshine Conversations connection** section, fill in the following fields:
        - **Authentication type**: select **API key** or **OAuth**.
        - **OAuth Connection**: if you selected **OAuth**, select your connection. With OAuth, the **Key ID** and **Secret** fields are hidden and the API version is fixed to `v2`.
        - **API version**: select either `v1.1` or `v2`, matching your Sunshine Conversations app.
        - **Key ID**: paste the key ID you copied from Sunshine Conversations.
        - **Secret**: paste the secret you copied.
        - **URI**: enter your app's base URI, for example, `https://app.smooch.io`. Omit the trailing `/`.
    3. Save changes.
  </Accordion>

  <Accordion title="4. Add a webhook in Sunshine Conversations">
    1. In your Sunshine Conversations app, go to **Settings > Integrations > Webhooks**.
    2. Click **Add Webhook**.
    3. Paste the Cognigy Endpoint URL you copied earlier into the **URL** field.
    4. For **Triggers**, select at least the following options:
        - `AppUser messages`
        - `Postbacks`
    5. Ensure the **API Version** matches your Cognigy Endpoint version (v1.1 or v2). Save the webhook.
  </Accordion>
</AccordionGroup>
