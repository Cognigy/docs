The NiCE CXone AAH Endpoint enables you to connect [Agent Copilot](/agent-copilot/overview) directly to [NiCE CXone Agent Assist Hub (AAH)](https://help.nicecxone.com/content/aiassistantsandbots/agentassisthub/cognigyagentassist/cognigyagentassist.htm) in the NiCE CXone Mpower contact center. For more information, read the [Agent Copilot documentation on this Endpoint](/agent-copilot/deploy/nice-aah).
