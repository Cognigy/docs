Cognigy provides a wide range of endpoints and components, such as the interaction panel, xApp: Show Adaptive Card node, and Live Agent, for its conversational AI platform. However, not all of these endpoints and components can correctly convert your content to the intended output type.

If the endpoint or component doesn't support the selected output type, Cognigy falls back to text as a default output.

The following table shows the [output types](/ai/agents/develop/node-reference/basic/say) that Cognigy can provide for each endpoint or component with these notations:

- ![supported](/_assets/icons/check-circle.svg) — supports and converts the output type.
- ![not supported](/_assets/icons/x-mark.svg) — doesn't support the output type and falls back to plain text.
- N/A — the output type isn't applicable for the endpoint or component.
