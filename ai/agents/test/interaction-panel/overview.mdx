The _interaction panel_ is an interface for testing agents and flows. You can chat with an agent or call it, see how it responds, and trace what it does in each turn. Use the results to improve your agent's communication and service skills.

The interaction panel provides the following features:

- **Chat and voice testing.** Test an agent in [chat](/ai/agents/test/interaction-panel/chat) or [voice call](/ai/agents/test/interaction-panel/voice-call) mode. For flows, you can also use [live follow](/ai/agents/test/interaction-panel/live-follow) mode.
- **Tracing.** With **Advanced mode**, [trace](/ai/agents/test/interaction-panel/tracing) the LLM calls, tool calls, and skills of each turn.
- **Memory inspection.** For flows, view and extract the data stored in the [agent's memory](/ai/agents/develop/ai-agent-memory/overview).
- **Playbooks.** For flows, use [Playbooks](/ai/agents/test/playbooks) to automate repetitive tests and catch errors efficiently.

## Prerequisites

- An agent or a [flow](/ai/agents/develop/projects-and-flows/overview) with configured [nodes](/ai/agents/develop/nodes/overview) in your project.

## Explore the interaction panel

To open the interaction panel, click ![Toggle interaction panel](/_assets/icons/blue/interaction-panel.svg) **Toggle interaction panel** in the upper-right corner. You can open the interaction panel from any page of your project. To close it, click the **X** icon in its header.

### Advanced mode

**Advanced mode** shows more information about a conversation. It turns on [tracing](/ai/agents/test/interaction-panel/tracing) and the modes and tabs that only flows have. To turn on **Advanced mode**, click the flask icon in the header, or use the settings. **Advanced mode** is off by default. If you turn it off while a flow-only mode is open, the interaction panel switches to chat mode.

## Configure the interaction panel

To open the settings, click the gear icon in the header. The interaction panel stores the settings per user and per project in your browser. To return all settings to their defaults and to reset the session, click **Reset to default values**.

<Accordion title="Settings">
  | Section | Setting | Type | Description | Default |
  |---------|---------|------|-------------|---------|
  | **Advanced mode** | **Advanced mode** | Toggle | Displays tracing spans and data for debugging. | Off |
  | **Session configuration** | **Snapshot** | List | Sets the snapshot that you test. This setting is optional and available for flows and agents. If you select a snapshot, the lists of agents, flows, and locales show only items from that snapshot. If the selected agent or flow isn't in the snapshot, the interaction panel shows **Select an agent or flow**. Select an available one to continue. | **No snapshot** |
  | **Session configuration** | **Locale** | List | Sets the locale for testing the agent or flow. The primary locale is marked **Primary**. | None |
  | **Advanced mode preferences** | **Tracing spans per turn** | Toggle | Displays the tracing spans of each turn. If you turn it off, the interaction panel collapses the spans of each turn. | On |
  | **Advanced mode preferences** | **Display only error spans** | Toggle | Shows only spans with errors. This setting is linked to **Errors only** in the full tracing view. | Off |
  | **Advanced mode preferences** | **Persist advanced mode** | Toggle | Keeps **Advanced mode** on each time the interaction panel reloads. | Off |
  | **Chat and voice** | **Show JSON data payload field** | Toggle | Displays the **JSON data payload** field below the message input. If the JSON is invalid, you can't send the message. | Off |
  | **Chat and voice** | **Render markdown** | Toggle | Displays messages with rendered Markdown syntax. | On |
  | **Chat and voice** | **Text to speech** | Toggle | Plays the agent's outputs aloud. The interaction panel disables the setting if your browser doesn't support speech synthesis. The interaction panel doesn't keep this setting. | Off |
  | **Chat and voice** | **Language** and **Voice** | List | Set the language and the voice for text to speech. Select **Custom** to enter a language code, for example, `en-US`, and a voice name or ID. If you change the language, the interaction panel clears the voice. | None |
  | **Advanced** (flows only) | **NLU connector** | List | Sets the NLU connector that the flow uses. | **Cognigy** |
  | **Advanced** (flows only) | **Channel to display** | List | Sets the channels that the interaction panel displays, such as Webchat, Voice Gateway, and Slack. | **All channels** |
  | **Advanced** (flows only) | **Mocking** | Toggle | Activates [mocking](/ai/agents/test/mocking) for nodes that have mock code configured. The setting appears only if mocking is enabled for your environment. | Off |
  | **Advanced** (flows only) | **Auto-move in flow editor** | Toggle | Moves the flow editor to the node that runs. | On |
  | **Advanced** (flows only) | **Auto-switch to target flow** | Toggle | Switches the flow editor to the flow that runs. | On |
  | **Playbooks** (flows only) | **Repeat playbook** | Toggle | Repeats the playbook. | Off |
  | **Playbooks** (flows only) | **Delay (ms)** | Number | Sets the delay in milliseconds for Playbook runs. The value must be a whole number, 0 or higher. | 200 |
</Accordion>

The **Advanced** and **Playbooks** settings are available when **Advanced mode** is on.
