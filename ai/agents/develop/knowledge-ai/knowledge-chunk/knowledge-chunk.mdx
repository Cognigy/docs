A _knowledge chunk_ is a knowledge unit extracted from a [knowledge source](/ai/agents/develop/knowledge-ai/knowledge-source/overview). Knowledge chunks are smaller, self-contained pieces of information that Knowledge AI can process and send to agents.

A knowledge chunk can be a single paragraph, a sentence, or even a smaller unit of text from a knowledge source. By dividing the content into knowledge chunks, Knowledge AI gains better granularity to process information. This way, Knowledge AI analyzes and responds to user queries more efficiently and accurately. Use the [chunk editor](/ai/agents/develop/knowledge-ai/knowledge-chunk/knowledge-chunk-editor) to edit and manage knowledge chunks.

Knowledge chunks include [knowledge chunk text](#knowledge-chunk-text) and [chunk metadata](#chunk-metadata).

## Restrictions

- The knowledge chunk text field can't be empty or contain only whitespace. The same rule applies to the `text` parameter in the [Cognigy Knowledge Chunks API endpoint](https://api-trial.cognigy.ai/openapi#tag--Knowledge-Chunks).

## Limitations

- You can add up to 1000 knowledge chunks per knowledge source.
- Knowledge chunk text can have up to 2000 characters.
- Knowledge chunk texts can contain bulleted and numbered lists in Markdown format. Other elements, such as links, may not display correctly in the chat conversation.
- Each chunk metadata value can have up to 1000 characters.
- You can add up to 20 knowledge chunk metadata pairs per knowledge chunk.

## Knowledge chunk text

[Knowledge AI extracts information from files](/ai/agents/develop/knowledge-ai/knowledge-source/text-extraction/overview) and processes their content into knowledge chunk text. You can also create knowledge chunks directly in [CTXT files](/ai/agents/develop/knowledge-ai/knowledge-source/text-formats/ctxt).

## Chunk metadata

Chunk metadata contains information related to the knowledge chunk. Chunk metadata is optional and can supplement the content of your agent's answers, for example, with links and images.

You can add metadata as key-value pairs to knowledge chunks in the chunk editor or directly to a [CTXT file](/ai/agents/develop/knowledge-ai/knowledge-source/text-formats/ctxt). Knowledge chunks support only numbers, strings, and booleans as chunk metadata.

You can store chunk metadata in the [input object](/ai/agents/develop/ai-agent-memory/input) or [context object](/ai/agents/develop/ai-agent-memory/context) and give your agents access to chunk metadata through:

- `input.knowledgeSearch.topK[0].chunkMetaData.{key}` in the [input object](/ai/agents/develop/ai-agent-memory/input)
- `context.knowledgeSearch.topK[0].chunkMetaData.{key}` in the [context object](/ai/agents/develop/ai-agent-memory/context)

Where `{key}` is your chunk metadata key.

You must format chunk metadata as key-value pairs wrapped in backticks, for example, `` `url: https://www.cognigy.com` ``. The key refers to the information the metadata holds, and the value is the information.

### Chunk metadata examples

You can find examples of common chunk metadata by key in the following table:

| Key     | Description                                                        | Example                                                                                    |
|---------|--------------------------------------------------------------------|--------------------------------------------------------------------------------------------|
| `url`   | Links to external sources or additional reading material.          | `` `url: https://docs.cognigy.com/ai/agents/develop/node-reference/other-nodes/search-extract-output` `` |
| `image` | Graphics that illustrate the information in the knowledge chunk.   | `` `image: https://docs.cognigy.com/ai/images/xApp/architecture.png` ``                          |
| `video` | Multimedia content that helps users comprehend the knowledge chunk text. | `` `video: https://www.youtube.com/watch?v=U87psHIQF3w` ``                                       |

For example, for the `url: https://docs.cognigy.com/ai/agents/develop/node-reference/other-nodes/search-extract-output` chunk metadata stored in the input object, where `url` is the key, retrieve this information by using `input.knowledgeSearch.topK[0].chunkMetaData.url`.
