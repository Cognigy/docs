This guide walks you through the process of creating an agent that uses Knowledge AI to search a knowledge database, extract information, and output answers generated by a large language model (LLM). You'll learn how to create your first knowledge store, upload knowledge sources, and test your agent using the interaction panel in the flow editor.

## Prerequisites

- You have [activated Knowledge AI](/ai/agents/develop/knowledge-ai/activate).
- You have created a [project](/ai/agents/develop/projects-and-flows/projects) in Cognigy.
- You have added a [large language model (LLM) to your project](/ai/agents/develop/gen-ai-and-llms/providers/all-providers) that [supports knowledge search and answer extraction](/ai/agents/develop/gen-ai-and-llms/model-support-by-feature). For more details on how to add a model, read the [Generative AI](/ai/agents/develop/gen-ai-and-llms/llms) documentation.

## Configure knowledge for an agent

To configure [knowledge](/ai/agents/develop/knowledge-ai/knowledge-store) for an agent, complete the following steps:

<Steps>
<Step title="Create knowledge store">

1. In your project, go to **Design > Knowledge**.
2. In the **Create knowledge store** wizard, configure the following:
  - **Name** — enter a unique name, for example, `xApps knowledge`.
  - _(Optional)_ **Description** — provide a brief description of the knowledge store.
3. Click **Save**. The newly created knowledge store appears on the **Knowledge** page.

</Step>
<Step title="Create knowledge source">

For this step, download [this Cognigy text (CTXT) file](https://docscognigyassets.blob.core.windows.net/assets/cognigy-sample.ctxt) about xApps.

1. On the **Knowledge** page, select the knowledge store you created.
2. Click **Add knowledge** and select **CTXT file**.
3. Drag and drop the CTXT file to the field on the **Upload CTXT file** page or click **Browse files** and select the CTXT file from your device.
4. Click **Save**.

</Step>
<Step title="Configure agent with knowledge">

1. Go to **Design > Agent** and follow one of the options:
  - Edit an agent by selecting ![menu](/_assets/icons/black-and-white/vertical-ellipsis.svg) **> Edit**.
  - Create an agent by clicking **+ Create agent** and configure the following:
      - **Name** — enter a unique name, for example, `xApps Expert`.
      - **Instructions** — enter instructions about what the agent must accomplish, for example, `You help customers with questions about Cognigy`.
2. In the **Select knowledge store** section on the **Knowledge** tab, configure the following:
      - **Search** — select **Agent decides**.
      - **If search fails** — select **Decline with generic error**.
3. From the knowledge store list, select the knowledge store you created. The **Search instructions** field appears.
4. In the **Search instructions** field, enter when the agent must search the knowledge store for an answer, for example, `Use this knowledge store when the user asks about xApps`.

</Step>
<Step title="Test your agent's knowledge">

1. Click ![interaction panel](/_assets/icons/black-and-white/interaction-panel.svg) to open the interaction panel.
2. Ask the agent `What are xApps?`. The agent searches the knowledge store and generates an answer in the chat.

</Step>
</Steps>

## Use knowledge with flows

If your agents use flows, you can also retrieve information from a knowledge store with the [Search Extract Output node](/ai/agents/develop/knowledge-ai/knowledge-search-and-extraction/search-extract-output).

## What's next?

1. Try creating a [knowledge store](/ai/agents/develop/knowledge-ai/knowledge-store) with [knowledge sources](/ai/agents/develop/knowledge-ai/knowledge-source/overview) relevant to your business needs.
2. Add more than one knowledge store to your agent with a knowledge tool to cater to your needs.
