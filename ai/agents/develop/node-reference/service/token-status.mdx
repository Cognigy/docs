## Description

The Token Status Node checks whether a valid Microsoft SSO token exists for an [Azure Bot Service Endpoint](/ai/agents/deploy/endpoint-reference/azure-bot-services)'s OAuth connection, and branches the Flow into **Granted** or **Not Granted** child Nodes for further execution.

Place this Node after a [Get Token](/ai/agents/develop/node-reference/service/get-token) Node to check whether the sign-in completed, before continuing with an action that requires the token.

## Parameters

| Parameter            | Type          | Description                                                                                                                                                                                                                                              |
| -------------------- | ------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Overwrite Connection | Toggle        | Sets a different OAuth connection than the one configured in the **SSO Connection Name** parameter in the Endpoint settings. Use this toggle if you use multiple SSO connections with your Azure Bot Service. This parameter is deactivated by default. |
| Connection Name      | CognigyScript | This parameter appears when you activate **Overwrite Connection**. Sets the name of the OAuth connection to check the token for.                                                                                                                         |
