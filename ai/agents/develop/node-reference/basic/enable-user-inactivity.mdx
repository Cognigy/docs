## Description

The Enable User Inactivity node starts checking for user inactivity in the current Webchat v3 session. When the user stays silent for longer than the timeout, the text and data configured in the [Webchat v3 endpoint](/webchat/v3/user-inactivity) are injected into the flow.

To disable the user inactivity check, use the [Disable User Inactivity node](/ai/agents/develop/node-reference/basic/disable-user-inactivity).

## Prerequisites

- In the Webchat v3 endpoint settings, set **Flow** to the flow containing this node and turn on **Enable User Inactivity** in the **User inactivity** section on the **Behavior** tab. While this setting is turned off, the node has no effect.

## Parameters

| Parameter | Type   | Description                                                                                                                                                                                                                                                                                                                                              |
|-----------|--------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Timeout   | Number | Defines how long to wait for a user message, in seconds, before the user is considered inactive. The timer starts after the agent message and is reset when the user sends a message. The default value is `30`. The minimum value is `3`, and the maximum value is `259200` (72 hours). |
