The _Flow Editor_ is a user interface (UI) where you can see a graphic representation of a [Flow](/ai/agents/develop/projects-and-flows/overview), the _Flow Chart_, and design agent conversations. In the flow editor, the flow consists of nodes that represent various actions or decision points. The [Nodes](/ai/agents/develop/nodes/overview) are linked to one another by lines that indicate the conversation's path, from the **Start** Node to the **End** Node.

The flow editor allows for [Collaborative Editing](/ai/agents/develop/projects-and-flows/collab-editing). This means that multiple users can edit the same flow at the same time.

A green arrow next to a node indicates the Flow Entrypoint. The Entrypoint is where the agent expects a user entry. The flow editor highlights the path of the conversation in green. The green path allows you to understand the flow execution path at each step, depending on the input in the [Interaction Panel](/ai/agents/test/interaction-panel/overview).

## Limitations

- A warning appears when a flow has more than 100 nodes. To keep performance high, split large flows into smaller ones.

## Node context menu

Right-click a node in the flow chart to open its context menu.

<Frame>
  <img src="/_assets/ai/develop/flows/flow-node-context-menu-c26.webp" alt="Context menu opened on a Say Node in the Flow editor, listing Copy, Cut, Paste, Disable, Set Entrypoint, Add Comment, Start Discussion, Enable Mocking, and Delete." style={{ width: 'auto' }} />
</Frame>

For a Say Node, the menu includes the following options:

- **Copy**, **Cut**, and **Paste**
- **Enable** and **Disable**
- **Set Entrypoint** and **Unset Entrypoint**
- **Add Comment** and **Edit Comment**
- **Start Discussion** or **Open Discussion**
- **Enable Mocking**, when the feature is enabled for your organization
- **Delete**

**Collapse**, **Uncollapse**, and **Create Flow From Branch** appear only on child nodes, such as the cases of a Lookup Node.

The **Start** and **End** Nodes don't have a context menu.

## Add nodes

To add a node, click the plus (+) button on the chart line where you want the node. A popover opens with two tabs:

- **By Function**
- **Extensions**

The popover includes a search field. Enter a command or search term to find a node. Category tabs filter the list: **All**, **Basic**, **Logic**, **AI**, **Voice**, **Analytics**, **CXone**, **Service**, and **Data**. Select a node to add it to the flow.

## Keyboard shortcuts

In the flow chart, you can use the following keyboard shortcuts:

| Action | Windows and Linux | macOS |
|--------|-------------------|-------|
| Copy | <kbd>Ctrl</kbd> + <kbd>C</kbd> | <kbd>Cmd</kbd> + <kbd>C</kbd> |
| Cut | <kbd>Ctrl</kbd> + <kbd>X</kbd> | <kbd>Cmd</kbd> + <kbd>X</kbd> |
| Paste | <kbd>Ctrl</kbd> + <kbd>V</kbd> | <kbd>Cmd</kbd> + <kbd>V</kbd> |
| Undo | <kbd>Ctrl</kbd> + <kbd>Z</kbd> | <kbd>Cmd</kbd> + <kbd>Z</kbd> |
| Redo | <kbd>Ctrl</kbd> + <kbd>Y</kbd> | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>Z</kbd> |
| Delete | <kbd>Delete</kbd> | <kbd>Delete</kbd> |
| Search for nodes | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>F</kbd> | <kbd>Cmd</kbd> + <kbd>Option</kbd> + <kbd>F</kbd> |
