Cognigy offers a platform-provided LLM that you can use only for embedding models in [design-time features](/ai/agents/develop/flow-agents/design-time-and-run-time-features#design-time-generative-ai-features). This model is fully integrated into the platform and requires no additional setup or configuration.

## Prerequisites

- The platform-provided LLM is available only for SaaS installations.

## Apply the model

Starting with version 2025.14, this model is selected by default for design-time features in new projects.

To apply another model, go to **Manage > AI & Voice Providers > Language Models > Assignments** and select a model for **Design-Time Features**.

For projects created before 2025.14, the model you previously selected will remain in use.
