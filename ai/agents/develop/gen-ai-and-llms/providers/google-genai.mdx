## Add models

You can add a model using one of the following interfaces:

- [GUI](#add-models-via-gui)
- [API](#add-models-via-the-api)

### Add models via GUI

You can add a model provided by Google GenAI to Cognigy in **Manage > AI & Voice Providers > Language Models**. In **Generative AI Connection**, select an existing connection or click the + button to create one. The connection stores the credentials. To add the model, you'll need the following parameters:

<Tabs>
  <Tab title="Standard model">

        | Parameter | Type | Description |
        |---|---|---|
        | Credentials File | JSON | To upload the JSON file with a key for your model, you need to obtain this key. If you've previously used a key for the Google Vertex AI or Google Gemini connection, you can reuse this key for Google GenAI. If you're setting up the connection for the first time, go to the Google Cloud console and find Vertex AI via the search bar. On the **Vertex AI** page, click the **Enable All Recommended APIs** button to activate an API connection, if it isn't activated. Ensure that the Vertex AI API is enabled. In the left-side menu, go to the **IAM & Admin > Service Accounts**. Select **Actions** and click **Manage Keys**. On the **Keys** page, select **Add Key** and click **Create new Key**. In the appeared window, select the **JSON** key type and click **Create**. The file will be downloaded. |
        | Location | Text | Enter a [region](https://cloud.google.com/vertex-ai/docs/general/locations) for the model. For example, `us-central1`. |
  </Tab>
  <Tab title="Custom model">

<Note>
  The Google GenAI provider supports custom models based on any model from the [Gemini families](https://ai.google.dev/gemini-api/docs/models).
</Note>
        | Parameter | Type | Description |
        |---|---|---|
        | Type | List | Select the model type: **Chat** or **Embedding**. |
        | Custom model | Text | Enter the name of the model that you want to use as a custom model. To find model names, refer to the [Google GenAI](https://ai.google.dev/gemini-api/docs/models/gemini) documentation. |
        | Credentials File | JSON | To upload the JSON file with a key for your model, you need to obtain this key. If you've previously used a key for the Google Vertex AI or Google Gemini connection, you can reuse this key for Google GenAI. If you're setting up the connection for the first time, go to the Google Cloud console and find Vertex AI via the search bar. On the **Vertex AI** page, click the **Enable All Recommended APIs** button to activate an API connection, if it isn't activated. Ensure that the Vertex AI API is enabled. In the left-side menu, go to the **IAM & Admin > Service Accounts**. Select **Actions** and click **Manage Keys**. On the **Keys** page, select **Add Key** and click **Create new Key**. In the appeared window, select the **JSON** key type and click **Create**. The file will be downloaded. |
        | Location | Text | Enter a [region](https://cloud.google.com/vertex-ai/docs/general/locations) for the model. For example, `us-central1`. |

  </Tab>
