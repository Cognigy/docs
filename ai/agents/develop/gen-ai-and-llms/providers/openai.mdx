To start using an OpenAI model with Cognigy features, follow these steps:

1. [Add models](#add-models)
2. [Apply the model](#apply-the-model)

## Restrictions

- The `gpt-5-5`, `gpt-5-6-sol`, `gpt-5-6-terra`, `gpt-5-6-luna`, `gpt-6-sol`, `gpt-6-luna`, and `gpt-6-1-sol` models support only the Responses API.
- The `gpt-6-1-sol` model doesn't support the `"none"` and `"minimal"` values for `reasoning.effort`. As a result, you can't override its default `temperature`.

## Add models

You can add a model using one of the following interfaces:

- [GUI](#add-models-via-gui)
- [API](#add-models-via-the-api)

### Add models via GUI

You can add a model provided by OpenAI to Cognigy in **Manage > AI & Voice Providers > Language Models**. In **Generative AI Connection**, select an existing connection or click the + button to create one. The connection stores the credentials. To add the model, you'll need the following parameters:

<Tabs>
  <Tab title="Standard model">

    | Parameter | Type | Description |
    |---|---|---|
    | API Key | Text | Enter an API key from your OpenAI account. You can find this key in the [User settings](https://help.openai.com/en/articles/4936850-where-do-i-find-my-secret-api-key) of your OpenAI account. |
    | API Type | List | Select the API format for chat models. **Chat Completion** uses the [Chat Completions API](https://platform.openai.com/docs/api-reference/chat). **Responses** uses the [Responses API](https://platform.openai.com/docs/api-reference/responses). The default is **Chat Completion**. This option is only available for chat models that support both API types. |

  </Tab>
  <Tab title="Custom model">

    | Parameter | Type | Description |
    |---|---|---|
    | Type | List | Select one of the following options:<ul><li>**Chat**. Lets you use either the [Chat Completions](https://platform.openai.com/docs/api-reference/chat) or [Responses](https://platform.openai.com/docs/api-reference/responses) API for chat models.</li><li>**Completion**. Uses the `https://api.openai.com/v1/completions` API.</li><li>**Embedding**. Uses the `https://api.openai.com/v1/embeddings` API.</li></ul> For more information, refer to the [OpenAI Text Generation Models](https://platform.openai.com/docs/guides/text-generation) documentation. |
    | Custom model | Text | Enter the name of the model that you want to use as a custom model. To find model names, refer to the [OpenAI models](https://developers.openai.com/api/docs/models) documentation.<br/> |
    | API Key | Text | Enter an API key from your OpenAI account. You can find this key in the [User settings](https://help.openai.com/en/articles/4936850-where-do-i-find-my-secret-api-key) of your OpenAI account. |
    | API Type | List | This parameter appears if you select **Chat** in **Type**. Select one of the following API options for chat models:<ul><li>**Chat Completion**. Uses the `https://api.openai.com/v1/chat/completions` API. This option is selected by default.</li><li>**Responses**. Uses the `https://api.openai.com/v1/responses` API.</li></ul> Make sure the model supports the selected API type. |

  </Tab>
</Tabs>
