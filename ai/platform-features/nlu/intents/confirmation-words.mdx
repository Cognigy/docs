_Confirmation words_ let you define a custom list of words and phrases that the agent recognizes as `yes` or `no` responses.

This feature is useful for straightforward use cases where you need exact control over how the system recognizes affirmations
(`yes`, `yep`) or negations (`no`, `nah`).

Unlike machine learning-based intent matching, confirmation words rely on explicit, user-defined terms.
The agent matches user input directly against your list, ensuring predictable behavior without requiring extensive training.

## Key benefits

- **Simple and precise**. Confirmation words work well for small, predictable sets of responses.
- **Fully customizable**. You decide which words trigger `yes` or `no`.

## Restrictions

- The agent recognizes only exact matches or predefined synonyms from the **Confirmation Words** list.
- The agent doesn't adapt to new confirmation word variations unless you add them yourself.

## How to use

You can apply confirmation words globally across all flows in a project or customize them for a specific flow.

<Tabs>
  <Tab title="Project-level settings">
        To use confirmation words for all flows, do the following:

        1. In the navigation menu, go to **Manage > Settings**.
        2. On the **Settings** page, click **NLU Settings**.
        3. In the **General Flow Logic** section, select **Confirmation Words** from the **Yes/No Logic** list.
        4. In the **Positive Confirmation Words** and **Negative Confirmation Words** fields, enter the words, one per line.
        5. Click **Save**.
  </Tab>
  <Tab title="Flow-level settings">
        By default, all flows inherit the **Yes/No Logic** and confirmation words settings from the project-level configuration. You can override these settings for a specific flow.
        To use confirmation words for a specific flow, do the following:

         1. In the navigation menu, go to **Design > Flows** and open the flow.
         2. Go to the **Settings** tab, then select **Configuration**.
         3. In the **General Flow Logic** section, select **Confirmation Words** from the **Yes/No Logic** list.
         4. In the **Positive Confirmation Words** and **Negative Confirmation Words** fields, enter the words.
         5. Click **Save changes**.
  </Tab>
</Tabs>

## How to test

Check that confirmation words work as expected using the [Interaction Panel](/ai/agents/test/interaction-panel/overview):

1. In the existing flow, open the Interaction Panel by clicking the chat icon (<img src="/_assets/icons/black-and-white/interaction-panel.svg" width="16" height="16" alt="Chat icon" />) in the upper-right corner of the page.
2. In the flow editor, add a Question node and select the **Yes/No** input type.
3. Run the flow by typing a test response that includes a word from your **Confirmation Words** list, for example, `yes` or `nope`.
4. On the **Info** tab, select **Input** to view the Input object in JSON format. In the `input.type` object, you'll see the answer depending on the user input.
    
    Positive confirmation:

    ```json
    "type": "pAnswer",
    ```

    Negative confirmation:

    ```json
    "type": "nAnswer",
    ```
