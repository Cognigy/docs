The _handover status_ feature lets you manage and respond to the state of conversations handed over to human agents. This feature provides real-time updates on handover progress, allowing you to design dynamic, context-aware conversational experiences.

When a conversation is handed over to a human agent, your agent can react to the current handover status. The agent can then guide the flow based on whether the conversation is queued, actively handled, completed, or has encountered an issue.

This capability is particularly valuable when building experiences with Agent Copilot flows, as it allows you to deliver contextual messages and implement fallback handling tailored to the current handover state.

## Key benefits

Using handover status in your flows provides several benefits:

- **Improved user experience**. Keep end users informed about their status, estimated wait time, and position in the queue, while preventing confusion from duplicate chats.
- **Smarter automation**. Automatically route conversations based on real-time status, trigger fallback handling, or escalate when errors occur.
- **Context-aware communication**. Send tailored messages depending on whether a conversation is queued, active, completed, or in progress.
- **Flexible integration**. Compatible with multiple platforms, including Cognigy Live Agent, Genesys Cloud, and RingCentral Engage.

## How it works

To allow your agent to react to handover statuses, use a Lookup node directly after the Handover to Human Agent node or tool. A Lookup node creates different flow paths based on a chosen operand. You can use handover status as operands to control how the agent guides the flow forward.
