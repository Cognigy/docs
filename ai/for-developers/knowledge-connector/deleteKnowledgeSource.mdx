## Syntax

`api.deleteKnowledgeSource(params)`

## Description

Deletes a [knowledge source](/ai/agents/develop/knowledge-ai/knowledge-source/overview) and the related [knowledge chunks](/ai/agents/develop/knowledge-ai/knowledge-chunk/knowledge-chunk).

**Parameters:**

- `params`: `DeleteKnowledgeSourceParams` — configuration object containing the source ID:

| Parameter           | Type   | Description                     |
| ------------------- | ------ | ------------------------------- |
| `knowledgeSourceId` | String | The ID of the knowledge source. |

**Returns:** `Promise<{}>` — a promise that resolves to an empty object when the deletion is complete.

## Example

```js
await api.deleteKnowledgeSource({
  knowledgeSourceId: "ks_abc123def456"
});

console.log("Knowledge source deleted successfully");
```
