To set up the Live Agent account for your organization, follow these steps:

1. In the Cognigy interface, click the user menu at the bottom of the navigation menu.
2. Select **Admin Center**.
3. Click **Set up Live Agent**.

When you set up Live Agent for your organization, you can [set up the inbox for Live Agent](/live-agent/getting-started/live-agent-setup/live-agent-setup-inbox).

## Troubleshooting

If the **Set up Live Agent** button is disabled, it could be for the following reasons:

- You don't have the Cognigy Live Agent feature enabled.
- You don't have permissions to create a Live Agent account.
- There's already a Live Agent account created for your organization.
