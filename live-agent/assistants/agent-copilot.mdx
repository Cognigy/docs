## Set up endpoints

To configure your endpoint:

1. Go to **Deploy > Endpoints**.
2. Open your Webchat endpoint.
3. On the **Advanced** tab, go to the **Copilot** section.
4. In the **Copilot type** field, select **Workspace**.
5. In the **Copilot config** field, select a config you recently created via [API](/api-reference/agent-copilot-configuration/create-an-agent-copilot-configuration).
6. Click **Save**.
7. In Live Agent, go to **Profile Settings > Agent Copilot Workspace** and select **Enable Agent Copilot Workspace**. Alternatively, you can activate the workspace for all human agents in your project. To do this, go to **Settings > Account Settings > Agent Copilot Workspace** and select **Enable Agent Copilot Workspace**, then click **Update Settings**.

The endpoint setup is completed.

## Test Agent Copilot workspace

To test Agent Copilot, follow these steps:

1. Start a Webchat session.
2. Complete the handover process to Live Agent.
3. Once the handover is complete, send a message as a human agent.
4. After that, send a message as the user in Webchat.

## Troubleshooting

### Transcript tile not sending messages

To send messages from the transcript tile chat to the end user's conversation chat, assign a human agent.
If the conversation remains unassigned, the transcript tile won't operate properly, as there will be no human agent to associate with the message when it is created.
