The _Overview Report_ gives you a quick summary of how customers are interacting with your agent.

The summary of key metrics is represented in the following charts:

- [Indicators](/insights/reports/engagement#indicators) 
- [Bar charts](/insights/reports/engagement#bar-charts)
- [Line charts](/insights/reports/engagement#line-charts)

All charts display data based on the global filter settings you've selected.

## Indicators

### Active sessions

Indicates the total number of currently active user sessions in the last 15 minutes. This widget updates in a regular interval of 30 seconds.

### Total sessions

Indicates the total number of sessions.

### Tasks reached

Indicates the total number of completed tasks. For more information, see [Tasks Reached](/insights/reports/engagement#tasks-reached) in the Engagement report.

### Containment rate

Indicates the ratio of sessions without any handover to all sessions. For more information about the formula, see [Containment Rate](/insights/reports/engagement#containment-rate) in the Engagement report.

### Top tasks

Indicates the number of sessions in which each task was completed. The task completed in the most sessions is ranked first. A task completed several times within the same session is counted once.

Source table:

```txt 
| Sessions    | Tasks                  |
| ----------- | ---------------------- |
| session-123 | Task A, Task B, Task D |
| session-456 | Task B, Task C, Task E |
| session-789 | Task A, Task B, Task E |
| session-abc | Task A                 |
| session-def | Task, Task A           |
| session-ghi | Task, Task A           |
| session-jkl | Task A, Task B, Task A |
```

In `session-jkl`, Task A appears twice but is counted only once.
