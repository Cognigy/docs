The _Conversations Explorer_ is an analytics tool in Cognigy Insights that helps you improve your agent's performance,
provide better customer service, and enhance the overall user experience.
It allows you to analyze transcripts of conversations between end users and agents in detail.
The Conversations explorer has a search feature that lets you look for specific phrases within a list of transcripts.
For example, you can search for keywords such as booking, canceling, or messaging to find relevant messages quickly.

<Note>
  Sessions with personal data masked using the [Delete Profile](/ai/agents/develop/node-reference/analytics/delete-profile) or [Deactivate Profile](/ai/agents/develop/node-reference/analytics/deactivate-profile) Nodes are excluded from the Conversations explorer.
</Note>

To open the Conversations explorer, use one of the following options:

<Tabs>
  <Tab title="Via Cognigy">
        1. Select a Project.
        2. In the navigation menu, select **Products > Insights**.
        3. In the navigation menu of the Insights interface, select **Conversations**.
  </Tab>
  <Tab title="Via Insights">
        In the left-side menu of the Insights interface, select **Conversations**. The Conversations explorer interface will be displayed.

        </Frame>
  </Tab>
</Tabs>

## List of sessions

By default, the Conversations explorer displays a filtered list of sessions for the last month.

The list of sessions has the following parameters:

| Title        | Description                                                                                                                                                                                              |
|--------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Endpoint     | The Endpoint handling the session. For example, Cognigy Webchat or the Interaction Panel.                                                                                                                |
| Session ID   | The unique ID for each session. <br/> To copy the Session ID, on the right side of the selected session row, click ![menu](/_assets/icons/black-and-white/vertical-ellipsis.svg) **> Copy session ID**. |
| User ID      | The unique ID for the end user. To copy the User ID, on the right side of the selected session row, click ![menu](/_assets/icons/black-and-white/vertical-ellipsis.svg) **> Copy user ID**.            |
| Messages     | The total number of messages within the specific session.                                                                                                                                                |
| Last Message | The date and time when the last message was received within the session.                                                                                                                                 |
| Analysis     | Reflects whether the session has been analyzed by [Conversation Analyzer](/insights/conversation-analyzer/overview). |

### Sort sessions

Sessions can be sorted by their `Session ID`, `Messages`, or `Last Message` parameters. To select a sorting parameter, hover over a column title and select the option you prefer:

- Click the up arrow ![sort ascending](/_assets/icons/black-and-white/arrow-up-black.svg) to sort in ascending order.
- Click the down arrow ![sort descending](/_assets/icons/black-and-white/arrow-down-black.svg) to sort in descending order.

## Search for sessions

To find specific sessions, do the following:

1. In the upper-right corner of the **Conversations** page, locate the search field.
2. In the search field, specify text messages (for more precise results, use keywords or phrases), Session ID, or User ID.

The Conversations explorer immediately updates the list of sessions according to the search results.

## Filter sessions

There are several filters available to filter sessions. The filter bar, featuring global and local filters, is visible at the top of the page. Some filters are not immediately visible and require clicking **more filters** to be viewed and selected. 
You can filter sessions by using the following options:

- [Global Filters](#global-filters)
- [Local Filters](#local-filters)

To hide the **Filter Bar**, click ![filter](/_assets/icons/black-and-white/insight-filter-black.svg) in the upper-right corner.

### Global filters

For more information, read the [Global Filter](/insights/global-filters) documentation.

### Local filters

Local filters are unique to a specific explorer/report. You can use them to refine your research.

To open the **Local Filters** selection,
click **more filters ![filter](/_assets/icons/black-and-white/insight-filter-black.svg)** in the filter bar at the top of the **Conversations** page.

| Filter              | Description                                                                                                                                                                                                                                                                                                                           |
|---------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Source              | Select one or more message sources: <br/> - **User Messages** — messages sent by users. <br/> - **Virtual Agent Messages** — messages sent by agents. <br/> - **Agent Messages** — messages sent by human agents.                                                                                                                          |
| Tasks               | Select from predefined tasks to narrow down results according to specific objectives or targets configured with the [Complete Task](/ai/agents/develop/node-reference/analytics/complete-task) Node.                                                                                                                                                                   |
| Contains Step       | Refine your search results by selecting a predefined analytic step. To access analytic steps, ensure you define descriptive names in the Node settings of your Flow within Cognigy. These steps are crucial for identification and analysis within Cognigy Insights, as they are logged once Nodes are passed during interactions. |
| Flow                | Specify one or more Flows to filter messages generated during the selected Flow passing.                                                                                                                                                                                                                                              |
| Message count: From | Set a minimum threshold for the number of messages in a session to be considered. Use the up and down arrow icons to specify the exact number. Sessions with fewer messages than this threshold will not be included in the results.                                                                                                  |
| Message count: To   | Set a maximum threshold for the number of messages in a session to be considered. Use the up and down arrow icons to specify the exact number. Sessions with more messages than this threshold will not be included in the results.                                                                                                   |

The **Message Rating**, **Goals**, and **Target Type** filters are global filters. For more information, see [Global filters](/insights/global-filters). If you select **AI Agents** in the **Target Type** filter, the **Message Rating**, **Goals**, **Tasks**, **Contains Step**, and **Flow** filters are disabled.

## View session transcripts

Session transcripts are logged conversations between end users and agents. 
The Conversations explorer enables you to view session transcripts and analyze them to understand interactions between end users and agents better.
To view a session transcript, select a session from the list on the **Conversations** page.

### Session transcript

Session transcripts display all individual messages between the end user and agent during their conversation. By selecting a session, the corresponding transcript will be displayed on the right side of the page.
You can use the scroll bar to navigate through the messages in the **Session Transcript** window.

<Note>
  The Session Transcript interface in the Conversations explorer is specifically designed for detailed analysis of past sessions, whereas the [Interaction Panel](/ai/agents/test/interaction-panel/overview) is primarily used for testing and debugging Flows.
  When you access a session transcript in the Conversations explorer, you may observe differences compared to the Interaction Panel. For example, the format and content of debug messages vary between these two tools.
</Note>

#### Debug mode

Insights' Debug mode is not fully equal to the Debug mode in the [Interaction Panel](/ai/agents/test/interaction-panel/chat#debug-mode) documentation. Debug messages from Nodes (including Code Nodes and Debug Message Nodes) are only for immediate testing and can only be seen in the Interaction Panel.

The Debug mode offers additional context for conversation messages, including:

- Triggered Intent and its score
- Filled Slots
- User connection and disconnection events
- Voice event payloads
- xApp session details

Additionally, you can switch to a Flow related to the current session.

To use Debug mode, activate the **Debug mode** toggle at the top of the **Session Transcript** window.

#### Scenarios

You can create a [scenario](/ai/agents/test/simulator/scenarios) based on a session transcript. Scenarios allow you to simulate user interactions and test your Flows effectively.

<Note>
  To create a scenario, an LLM model must exist on [the LLMs page](/ai/agents/develop/gen-ai-and-llms/providers/all-providers). By default, the LLM model marked as [`default`](/ai/agents/develop/gen-ai-and-llms/other-operations#set-a-model-as-default) will be selected.
</Note>

To create a scenario from a transcript, do the following:

1. In the upper-right corner of the **Session Transcript** window, click ![menu](/_assets/icons/black-and-white/vertical-ellipsis.svg) to open a selection menu.
2. Select **Create Scenario**. You will be redirected to the Simulator interface, where the Scenario will be created based on the selected transcript. The persona for the scenario will be generated from scratch. Click **Create**, then [follow the instructions](/ai/agents/test/simulator/simulations#run-a-simulation) to run the simulation.

Alternatively, you can create a scenario from a custom transcript in the [Simulator](/ai/agents/test/simulator/scenarios) interface.

#### Playbooks

To create a [Playbook](/ai/agents/test/playbooks) from a transcript, do the following:

1. In the upper-right corner of the **Session Transcript** window, click ![menu](/_assets/icons/black-and-white/vertical-ellipsis.svg) to open the selection menu.
2. Select one of the following options:
    - **Create Playbook** — generate a Playbook to test your Flows.
    - **Create Playbook with Assertions** — generate a Playbook and its Assertions, which are checks to ensure your Flows behave as expected during testing.

#### Download recordings and PCAP files

For sessions from Voice Gateway calls, you can download the call recording and the PCAP file of the call. A PCAP file contains the network traffic of the call. For more information about both, see Recent calls in the Voice Gateway documentation.

To download a file, do the following:

1. In the upper-right corner of the **Session Transcript** window, click ![menu](/_assets/icons/black-and-white/vertical-ellipsis.svg) to open the selection menu.
2. Select one of the following options:
    - **Download Recording** to download the call recording.
    - **Download PCAP** to download the PCAP file of the call.

The file name starts with the call SID. The recording contains only the caller track and the agent track. Voice Gateway keeps PCAP files for 14 days.

The options are available only if the following conditions are met:

- The session comes from a Voice Gateway call.
- You have permission to read the conversation history of the Project.
- Your environment includes agents. This is the same requirement as for the **Target Type** filter.
- For the recording, call recording is enabled in the Account or Application settings in Voice Gateway.

<Note>
  Cognigy checks for a recording when you open the session. While the check runs, **Download Recording** is unavailable. If the call has no recording, the option stays unavailable, and hovering over it shows **No recording for this call**.
</Note>

  If a download fails, Cognigy shows one of the following messages:

  | Message | Description |
  |---------|-------------|
  | This recording is no longer available. | The recording no longer exists. |
  | The PCAP for this call is no longer available. | The PCAP file no longer exists. |
  | The recording could not be read from the recording bucket. Check that the bucket connection can read files. | Cognigy can't read the recording from the recording bucket. Check the bucket connection. |
  | The download failed. Please try again. | Any other error. Try the download again. |

#### Open message-related flow

To check your [Flow](/ai/agents/develop/projects-and-flows/overview) or to improve its configuration, the Conversations explorer provides the **Open Flow** context menu option.

To switch from the Conversations explorer to the corresponding Flow in Cognigy, do the following:

1. In the left-side menu of the Insights interface, select **Conversations**.
2. On the **Conversations** page, select a session from the list. The session transcript will appear in a separate window on the right side of the page.
3. In the **Session Transcript** window, right-click a specific message and select **Open Flow**. The corresponding Flow in Cognigy appears.

### Session transcript details

The transcript details include the following sections:

- [Session Details](#session-details)
- [Call Details](#call-details)
- [Contact Profile Details](#contact-profile-details)

| Session Details        | Description                                                                                                                 |

#### Call details

The **Call Details** section appears only for sessions from Voice Gateway calls, and only if you have permission to read the conversation history of the Project. It appears below **Session Details**. The fields use the same terms as the Recent calls page in Voice Gateway. If Cognigy has no value for a field, the field shows a hyphen (-). Calls that took place before Cognigy started storing these fields can show a hyphen for the call identity fields.

| Call Details       | Description                                                                                                                             |
|--------------------|-----------------------------------------------------------------------------------------------------------------------------------------|
| Attempted At       | The time of the attempt.                                                                                                                |
| Call SID           | A unique identifier for the call. Specific for the call SIP sessions.                                                                   |
| Direction          | Whether the call was inbound or outbound.                                                                                               |
| Duration (Seconds) | The duration of the call in seconds.                                                                                                    |
| From               | The phone number of the party who made the call.                                                                                        |
| SIP Call ID        | A unique session identifier that you can use for several purposes, including call logging and billing correlation.                      |
| SIP Status         | A [SIP code response](https://en.wikipedia.org/wiki/List_of_SIP_response_codes).                                                        |
| Terminated At      | The time the call was ended.                                                                                                            |
| Termination Reason | The reason why the call was ended.                                                                                                      |
| To                 | The phone number of the party to whom the call was made.                                                                                |
| Trace ID           | A unique identifier for the call. Can be used to track any type of call or session as it passes through different parts of the network. |
| Trunk              | A [carrier](/ai/administer/access/speech-and-telephony#carriers) name.                                                                                       |

## Delete sessions

You can delete a session and its transcript
by selecting the session from the list on the **Conversations** page
and clicking ![menu](/_assets/icons/black-and-white/vertical-ellipsis.svg) **> Delete Session Transcript** in the **Session Transcript Details** window.
The session will be deleted from the Transcript and Message explorers.
However, the session metadata will remain accessible through the [Cognigy OData endpoint](/ai/agents/analyze/odata), except for the data in the [Conversation](/ai/agents/analyze/odata#conversations) collection.
Also, the Contact Profile details will still be available in the [Contact Profile](/ai/agents/analyze/contact-profiles).

<Note>
  If you've migrated to the new [Insights framework](/insights/data-management/pre-aggregation), there might be a delay between deleting the session transcript and the session itself. When you click the **Delete Session Transcript** button, the transcript is deleted first, and the session is deleted from the **Conversations** page about 10 minutes later.
</Note>
