The Webchat v3 key features offer comprehensive customization options, including branding elements, accessibility features, and tailored starting behaviors, ensuring a personalized and efficient user experience. Additionally, they include enhancements such as quick replies, conversation ratings, and privacy notices to elevate engagement and user feedback mechanisms. Features such as adaptive cards and media attachments enrich interactions by presenting structured content and media files seamlessly within the chat interface.

## Customization

Customization includes a comprehensive suite of features
that bolster your brand's presence and enhance user accessibility.
Customize the chat interface with your brand's title and logo,
alongside distinct avatars for both agents and human agents,
and adjust the color scheme across various elements.
Accessibility is prioritized with text-to-speech and speech-to-text functionalities.
Start behavior settings set the tone for engagement,
allowing for a tailored initial interaction, such as a start button or an automatic message.
Operational settings, including business hours, ensure users are clearly informed about the availability of support.
Collectively, these customization options create a personalized and efficient Webchat experience
that aligns with your operational requirements and brand image.

For customization, refer to the [Webchat layout](/webchat/v3/configuration#webchat-layout) and [Webchat behavior](/webchat/v3/configuration#webchat-behavior) settings.

## Home screen

The Webchat home screen offers a customizable and welcoming first impression for users,
facilitating immediate engagement. It includes a personalized welcome text to align with your brand's voice,
a background image for visual appeal, and a background color or gradient to match your brand's style.
These elements work together to create an inviting and branded entry point for user interactions, ensuring a seamless and appealing start to the chat experience.

### Conversation starters

The conversation starters feature can be activated in the **Home screen** settings and allows users to initiate conversations through predefined messages.
It provides a user-friendly start with options to customize these messages and to set the tone for the interactions. You can add up to five conversation starters and remove them when you no longer need them. This feature streamlines initiating dialogue, showcases agent capabilities, and ensures a smooth and guided conversation start.

### Previous conversations

The previous conversations feature offers a straightforward way for users to access their past dialogues with the agent directly from the Webchat home screen. You can customize the **Previous conversations button text** and the **Previous conversations title**, which appears in the header of the previous conversations screen. This enriches the user experience by ensuring continuity and easy reference to previous interactions.

## Chat options

Activating chat options adds interactive capabilities to the chat interface,
such as quick replies for streamlined responses, conversation rating for user feedback, text-to-speech options, and a customizable footer for further information.
Together, the features in the **Chat options** settings give users more ways to interact and give feedback, which improves the overall chat experience.

### Quick replies

The quick replies feature at the top of the chat options screen simplifies interactions by offering instant responses or directing users to more information. Users can choose from these options to address common questions or navigate to additional resources.

To configure the quick replies, refer to the [Quick replies](/webchat/v3/configuration#quick-replies) settings.

### Text-to-speech

The text-to-speech feature on the chat options screen is helpful for users who prefer or require listening over reading.
The feature enables the agent to speak messages aloud.
Users can choose whether to use this option, which lets them tailor their chat experience to their preferences.

To configure the text-to-speech feature, refer to the [Text-to-speech](/webchat/v3/configuration#text-to-speech) settings.

### Conversation rating

The conversation rating feature on the chat options screen allows users to rate and give feedback on their chat experience, which is crucial for improving agent performance. You can customize the rating title text, the comment placeholder text, the submit button text, and the banner text that confirms the rating was submitted. This streamlined feedback mechanism engages users directly, making it easier to gather and act on valuable user insights.

To configure the conversation rating, refer to the [Conversation rating](/webchat/v3/configuration#conversation-rating) settings.

## Privacy notice

The privacy notice feature ensures user trust and compliance by prompting users to accept a privacy notice before they chat with the agent. You can customize the title, the notice text, and the submit button text, and add a link to the full privacy policy. This transparently informs users about data handling practices and secures their informed consent.

## Controlling the chat window

The chat screen provides buttons for minimizing or closing the chat window:

- **Minimize chat**: this button collapses the window without ending a conversation. Users can return to the chat by expanding the window again. The `webchat/minimize` event is triggered when users click the **Minimize chat** button.
- **Close chat**: this button collapses the window without ending a conversation. Users can return to the chat by expanding the window again. The `webchat/close` event is triggered when users click the **Close chat** button.
    To make the **Close chat** button end the conversation and close the window, extend the [embedding file](/webchat/v3/embedding/hosted-script) with the following code:

    <Accordion title="webchat.endSession">
      ```js
      webchat.registerAnalyticsService(event => {
        if (event.type === "webchat/close") {
          webchat.endSession();
        }
      });
      ```
      For more information, see [Analytics API](https://github.com/Cognigy/Webchat/blob/main/docs/analytics-api.md) on GitHub.
    </Accordion>

## xApp overlay

By default, an xApp page opens in a separate browser tab.
In Webchat v3, you can change this behavior so that xApp pages open directly within the Webchat v3 interface.
Each xApp page is displayed on its own dedicated screen.
This approach helps users focus solely on the content of that page without distractions from other parts of the interface.
The design of xApp screens is consistent with other Webchat v3 screens such as [Home](#home-screen), [Chat options](#chat-options), and [Previous conversations](#previous-conversations).

## RTL language support

Alongside the traditional left-to-right (LTR) layout, Webchat v3 supports right-to-left (RTL). This feature is especially beneficial for languages such as Arabic,
Persian (Farsi), Hebrew, Urdu, and other languages that use this writing direction. Supporting RTL layouts lets users from various regions interact with the Webchat widget in their native languages, which enhances the user experience
and leads to more effective and personalized interactions with the agent.

All elements of the Webchat widget are aligned for RTL, including the positioning of the widget itself, which appears in the bottom-left corner of the web page. This adjustment ensures that users who speak languages with a right-to-left writing direction can easily interact with the chat, as it aligns with their usual reading and writing patterns.

<Frame>
  <img src="/_assets/webchat/v3/rtl-support.png" alt="Webchat v3 interface with right-to-left language layout" style={{ width: 'auto' }} />
</Frame>

To use RTL, add the attribute `dir="rtl"` to the `<html>` tag, which is placed at the beginning of the HTML page.
For more information, see [RTL configuration](/webchat/v3/embedding/hosted-script#rtl-configuration). To test this feature, [build Webchat v3 locally](https://github.com/Cognigy/Webchat/blob/main/README.md#development).
