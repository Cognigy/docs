If you need more control and flexibility than the **xApp: Show Adaptive Card** or **xApp: Show HTML** nodes
offer, you can create your own custom node.

To create a custom xApp extension, you'll need to build an [Extension](/ai/for-developers/extensions) from scratch using a [template](https://github.com/Cognigy/Extensions/tree/master/docs/example) provided in the Cognigy repository on GitHub. Below is the code snippet that you can use within the Extension.
This code snippet creates a custom node that displays text content and lets you cancel or continue the dialog.

```js
export const xappDialogNode = createNodeDescriptor({ 
  type: "xapp-dialog",
  fields: [
    {
      key: "content",
      label: "Content",
      type: "cognigyText",
    },
  ],
  function: (params) => {
    const { cognigy, config } = params;
    const { content } = config as any;


    // About the HTML code:
    // - Load the "app page SDK" from /sdk/app-page-sdk.js, which is always available for "generic HTML" apps. There's no need to include the SDK code within the HTML content.
    // - After the "app page SDK" line, you can use the SDK globally as it is now initialized.
    // - Use plain "onclick" handlers for the buttons to submit a result from the app by calling "SDK.submit({ action: '<action-description>' })".
    // - Clicking one of the buttons closes the app and triggers an "inject" message. The value of "input.data._cognigy._xapp.result" is equal to the parameters you provided in "SDK.submit" ({ action: '<action-description>' }).
    const getDialogHtml = (content) => `
<html>
    <head>
        <meta name="viewport" content="width=device-width, initial-scale=1">
        <script src="/sdk/app-page-sdk.js"></script>
    </head>
    <body>
        <p>${content}</p>
        <button type="button" onclick="SDK.submit({ action: 'continue' })">continue</button>
        <button type="button" onclick="SDK.submit({ action: 'cancel' })">cancel</button>
    </body>
</html>
`;
    // @ts-ignore
    cognigy.api.setAppState("generic-html", {
      html: getDialogHtml(content),
    });
  },
});
```

Use the `setAppState` function of the [xApp flow API](/xApps/api) with an `app template URL` set to `generic-html` and `app template data` that contain the generated HTML code.

After you implement the node, the generated HTML appears within the app screen, similar to the **xApp: Show HTML** node. This approach lets you edit a specific part of the page through node fields instead of modifying the entire page content. This streamlined process focuses on the changes that the dialog needs.
