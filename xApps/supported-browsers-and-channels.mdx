Cognigy xApps are compatible with the following browsers and channels.

## Supported browsers

xApps support the following browsers:

| Browser  | Versions                                      |
|----------|-----------------------------------------------|
| Firefox  | The newest version and two previous versions. |
| Chrome   | The newest version and two previous versions. |
| Chromium | The newest version and two previous versions. |
| Safari   | The newest version and two previous versions. |
| Edge     | The newest version and two previous versions. |

## Supported channels

xApps support the following channels:

- [Cognigy Voice](/ai/agents/deploy/endpoint-reference/voice-gateway)
- [Facebook (Meta) Messenger](/ai/agents/deploy/endpoint-reference/facebook-messenger)
- [LINE](/ai/agents/deploy/endpoint-reference/line-messenger)
- [Azure Bot Service](/ai/agents/deploy/endpoint-reference/azure-bot-services)
- [RingCentral Engage](/ai/agents/deploy/endpoint-reference/ringcentral-engage)
- [Slack](/ai/agents/deploy/endpoint-reference/slack)
- [Socket.IO](/ai/agents/deploy/endpoint-reference/socketio)
- [Sunshine Conversations](/ai/agents/deploy/endpoint-reference/sunshine-conversations)
- [WhatsApp](/ai/agents/deploy/endpoint-reference/whatsapp)
- [Webchat v3](/webchat/v3/overview)<sup>[1](#footnote1)</sup>
- [Webhook](/ai/agents/deploy/endpoint-reference/webhook)
- [REST](/ai/agents/deploy/endpoint-reference/rest)
