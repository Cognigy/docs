Cognigy exposes the URLs and the PIN code to access an xApp session as tokens.

## xApp PIN page URL

The xApp PIN Page URL token provides a URL to access the PIN Page.
You can get this URL when the [xApp: Init Session](/ai/agents/develop/node-reference/xApp/init-xApp-session#with-pin) node runs.
This URL is also accessible via `input.apps.baseUrl` in the input object.

## xApp session PIN

The xApp Session PIN token provides the PIN code to access the xApp session.
This PIN is also accessible via `input.apps.session.pin` in the input object.

The PIN code is valid for five minutes after the [xApp: Get Session PIN](/ai/agents/develop/node-reference/xApp/get-xApp-session-PIN) node creates it.

## xApp session URL

The xApp Session URL token provides the URL to access the xApp session without a PIN.
You can get this token
when the [xApp: Init Session](/ai/agents/develop/node-reference/xApp/init-xApp-session#without-pin) node runs.
This URL is also accessible via `input.apps.url` in the input object.
