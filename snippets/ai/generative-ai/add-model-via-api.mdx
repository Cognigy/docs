### Add models via the API

You can add either a standard or custom model using the [Cognigy API POST /v2.0/largelanguagemodels](/api-reference/large-language-models/create-a-large-language-model) request.
Then, test your connection for the created model via the [Cognigy API POST /v2.0/largelanguagemodels/{largeLanguageModelId}/test](/api-reference/large-language-models/test-large-language-model-connection).
