To apply a model, follow these steps:

1. In the navigation menu of the project, go to **Manage > AI & Voice Providers > Language Models**.
2. Click **Assignments**.
3. Find the capability that should use the model. Capabilities are grouped under **Runtime Features**, **Design-Time**, and **Knowledge**. For Knowledge AI, select a model for **Knowledge Search** and **Answer Extraction**. To find models that support these features, refer to [Model support by feature](/ai/agents/develop/gen-ai-and-llms/model-support-by-feature).
4. Select the model in the capability's list. If no model in the project supports the capability, **None** is selected and the list shows **No model in this project supports this capability**.
5. Click **Save changes**.
