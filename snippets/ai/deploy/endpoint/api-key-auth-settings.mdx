Use this section to configure how incoming requests to this Endpoint are authenticated.

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| Require API Key | Toggle | Activates API key-based authentication for requests sent to this endpoint. This setting is deactivated by default, so requests aren't authenticated. If you activate it, you need to enter an endpoint-specific API key in the header of your requests to this endpoint. To generate an endpoint-specific API key, use the **Generate API Key** button. |
| Generate API Key | Button | This button appears in the **Endpoint API keys** section when you activate **Require API Key**. Opens a dialog to generate an endpoint-specific API key. You can generate multiple endpoint-specific API keys. |
