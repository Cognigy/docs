### Configure Matching Custom Fields and Attributes

You can use [custom fields](https://help.nicecxone.com/content/acd/digital/managecustomfields.htm) in NiCE CXone and custom attributes in Cognigy.AI to:

- Display end-user data in the chat details.
- Fetch end-user data using the [CC Custom Fields card](https://help.nicecxone.com/content/studio/actions/ccard_fields/ccard_fields.htm).

To configure matching custom fields and attributes, follow these steps:

1. In the [NiCE CXone](https://cxone.niceincontact.com/) platform, click the **Applications** selector in the upper-left corner and select **ACD**.
2. In the navigation menu, select **Custom Fields**.
3. On the **Custom Fields** page, click **+ Create custom fields for Case** in the **Case Custom Fields** section.
4. On the **Edit custom field** page, configure the following:
    - **Ident** — enter the JSON key value you set in the **Custom Attributes** field in the [Handover to Human Agent](#2-add-a-handover-to-human-agent-node), for example, `customerType`.
    - **Label** — enter the field name displayed in the chat, for example, `Customer Type`.
    - **Type** — select the type that matches the data type of the value sent from Cognigy. For example, select **Text**, **E-mail**, or **Drop down list**.  For more information, refer to the [NiCE CXone](https://help.nicecxone.com/content/acd/digital/managecustomfields.htm) documentation.
    - **Is visible in post detail** — turn this on if you want the custom field and its value to be displayed in the contact details after the handover.
    - **Is editable** — turn this on if you want agents to be able to edit or override the value sent by Cognigy.
5. Click **Save**.

When you [test the handover](#4-test-the-handover), click **View Details** at the top of the chat. You will see the custom attribute sent from the Flow. For example, consider the following configuration:

- **Custom Attributes** in the Handover to Human Agent Node:

    ```json JSON Object
    {
      "customerType": "premium",
      "tags": "urgent"
    }
    ```
- In the custom field:
    - **Ident** — `customerType`
    - **Label** — `Customer Type`

After the handover, you can access this value by:

- Clicking **View Details** in the Agent Workspace. You will see the **Customer Type** field with the `premium` value.
- Using a [CC Custom Fields card](https://help.nicecxone.com/content/studio/actions/ccard_fields/ccard_fields.htm) in the Studio script to fetch the `customerType` value.
