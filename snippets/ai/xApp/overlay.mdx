<Accordion title="Webchat Overlay">

  By default, an xApp page opens in a separate browser tab.
  If you're using Webchat v3,
  you can override this behavior to open your xApp pages directly in Webchat v3.
  The pages are presented as screens.

  The following table lists the parameters for configuring xApp screens in the Webchat v3 interface.

  | Parameter                      | Type   | Description                                                                                                                                                                                                                                  |
  |--------------------------------|--------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
  | Header Title                   | Text   | This parameter shows the title of the screen. The title appears in the top panel of the Webchat v3 interface. If you don't provide a title, the top panel remains empty.                                                                     |
  | Show Close Icon                | Toggle | This parameter displays the `x` button in the upper-right corner of the screen. This parameter is activated by default.                                                                                                                      |
  | Send Event on Close Icon Click | Toggle | This parameter records the event when the user closes the screen without submitting. This parameter is deactivated by default.                                                                                                               |
  | Auto Open                      | Toggle | This parameter automatically opens the screen within the Webchat v3 interface. This parameter is activated by default. If you want xApp pages to open in browser tabs instead of within the Webchat v3 interface, deactivate this parameter. |
  | Close Overlay on Submit        | Toggle | This parameter closes the screen after the user clicks the Submit button. This parameter is activated by default.                                                                                                                            |
  | Feedback Message on Submit     | Text   | This parameter sends a message to the chat after the user clicks the Submit button.                                                                                                                                                          |
