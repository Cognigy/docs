Follow these recommendations each time you upgrade Cognigy products.

## Upgrade one minor version at a time

Don't skip minor versions. Always upgrade one minor version at a time, and review the [release notes](/release-notes/index) before you proceed. Skipping versions can lead to compatibility issues, missed database migrations, and configuration problems. Pay special attention to the Infrastructure section for any additional instructions.

## Use a test environment

Set up a separate test environment for Cognigy products. Use this environment to validate the upgrade and test your flows before you apply the same changes to production. This approach helps prevent unexpected issues and ensures a seamless transition to the new product version.

## Update with every release

In every release, we fix security vulnerabilities to ensure our products remain reliable and secure. We strongly advise you to update with each release, without skipping versions, to guarantee the highest level of protection and stability.
