The `say` verb converts text to speech and plays it to the caller. It supports multiple TTS vendors, languages, voices, and advanced options such as looping, early media, and fallback synthesizers.

```json expandable
{
  "verb": "say",
  "text": [
    "Hi there!",
    "Welcome to our service."
  ],
  "synthesizer": {
    "vendor": "google",
    "label": "primary-tts",
    "language": "en-US",
    "voice": "en-US-Wavenet-F",
    "engine": "neural",
    "gender": "FEMALE",
    "fallbackVendor": "aws",
    "fallbackLabel": "fallback-tts",
    "fallbackLanguage": "en-GB",
    "fallbackVoice": "Amy",
    "fallbackEngine": "neural",
    "options": {
      "audioConfig": {
        "speakingRate": 1.0,
        "pitch": 0.0,
        "volumeGainDb": 0.0
      }
    }
  },
  "loop": 2,
  "earlyMedia": true,
  "disableTtsCache": false
}
```

## Configuration

The following table lists the available parameters:

| Parameter                    | Type             | Description                                                                                                                                                                                                                                                                                                        | Required |
| ---------------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------- |
| text                         | string \| array  | The text to speak. The text may be either plain text or use SSML tags for advanced speech effects such as pauses, emphasis, or embedded audio. Can be a string or an array of strings. For example, `<speak>Hello, <break time='1s'/> welcome!</speak>`.                                                           | Yes      |
| synthesizer                  | string \| object | Defines the text-to-speech options. Can be an object with detailed TTS settings or a string referencing a pre-configured synthesizer.                                                                                                                                                                              | No       |
| synthesizer.vendor           | string           | The TTS service provider to use, for example, `google` or `aws`. This determines the available voices, languages, and engine options. See [supported speech vendors](/voice-gateway/references/tts-and-stt-vendors) or [add a custom speech API](/ai/administer/access/speech-and-telephony#speech-providers). | No       |
| synthesizer.label            | string           | A custom label for this synthesizer instance. Useful for logging or identifying multiple TTS configurations in a single flow. Can be `null` or a string.                                                                                                                                                           | No       |
| synthesizer.language         | string           | The language code for the speech output, for example `en-US` or `de-DE`. Required if a vendor is defined.                                                                                                                                                                                                          | No       |
| synthesizer.voice            | string \| object | The specific voice to use. Can be a string representing the vendor-specific voice name or an object with advanced properties. Defaults to the Application-level TTS voice if not provided. For example, `en-US-Wavenet-F` for Google TTS.                                                                          | No       |
| synthesizer.engine           | string           | The TTS engine type. Options are: <ul><li>**standard** – speech built by joining recorded speech segments</li><li>**neural** – higher-quality, more natural-sounding speech than **standard**</li><li>**generative** – the most human-like, conversational voices</li></ul>                      | No       |
| synthesizer.gender           | string           | The desired voice gender: `MALE`, `FEMALE`, or `NEUTRAL`. Used for vendors that support gender selection.                                                                                                                                                                                                          | No       |
| synthesizer.fallbackVendor   | string           | An alternative TTS vendor to use if the primary vendor fails or returns an error. For example, `aws`.                                                                                                                                                                                                              | No       |
| synthesizer.fallbackLabel    | string           | A label for the fallback TTS instance. Helps distinguish the primary and fallback synthesizers in logs.                                                                                                                                                                                                            | No       |
| synthesizer.fallbackLanguage | string           | The language code for the fallback synthesizer, for example `en-US` or `de-DE`. Defaults to the primary language if not provided.                                                                                                                                                                                  | No       |
| synthesizer.fallbackVoice    | string \| object | The voice for the fallback synthesizer. Can be a string or object. For example, `Amy` for AWS.                                                                                                                                                                                                                     | No       |
| synthesizer.fallbackEngine   | string           | The TTS engine for the fallback synthesizer. The options are the same as for `synthesizer.engine`. The engine applies only if the fallback speech provider supports engine selection, for example, AWS. | No       |
| synthesizer.options          | object           | An object with settings for the speech provider, nested as the speech provider's own API expects. For example, with Google, `speakingRate` from 0.25 to 2.0, `pitch` from -20 to 20, and `volumeGainDb` from -96 to 16 go inside `audioConfig`. Settings that the speech provider expects as query parameters go in a nested `queryOptions` object. See [Synthesizer options](#synthesizer-options) for the fields that each speech provider accepts. | No       |
| loop                         | number           | The number of times to repeat the utterance. Set 0 for infinite repetition. The default value is 1. Useful for hold music or repeated prompts.                                                                                                                                                                     | No       |
| earlyMedia                   | boolean          | If true and the call isn't yet answered, plays the audio without officially answering the call. Useful for IVR previews or ringback messages. The default value is false.                                                                                                                                         | No       |
| disableTtsCache              | boolean          | If true, disables caching of the synthesized audio for this utterance. The default value is false.                                                                                                                                                                                                                 | No       |

## Synthesizer options

Synthesizer options let you pass settings to the speech provider, such as the speaking rate, the voice style, or text normalization. Use them when the standard `synthesizer` parameters, such as `voice` and `language`, don't cover a speech provider setting.

### Configure options

Add the settings to `synthesizer.options`. Settings that the speech provider expects as query parameters go in a `queryOptions` object inside `options`:

```json
{
  "vendor": "<vendor>",
  "options": {
    "<field>": "<value>",
    "queryOptions": {
      "<field>": "<value>"
    }
  }
}
```

Note the following:

- Nesting: Nest the fields the way the speech provider's API does. ElevenLabs options are mostly flat, but Google expects `speakingRate` and `pitch` inside `audioConfig`.
- Supported fields: Each speech provider accepts only the fields listed in [Options by speech provider](#options-by-speech-provider). If a field isn't one of them, Voice Gateway ignores that field and applies the rest.
- Invalid values: If a value has the wrong type or is out of range, Voice Gateway ignores all the options for that request and synthesizes the speech without them.
- Parameters that options can't override: Set the voice, language, and engine with `synthesizer.voice`, `synthesizer.language`, and `synthesizer.engine`. Options can't override them.

### Options by speech provider

The tables list the fields that you can set for each speech provider. Fields that start with `queryOptions.` go in the `queryOptions` object inside `options`.

<AccordionGroup>

  <Accordion title="ElevenLabs">

For details, see the [ElevenLabs text-to-speech API](https://elevenlabs.io/docs/api-reference/text-to-speech/convert).

| Field | Values | Description |
| ----- | ------ | ----------- |
| `apply_text_normalization` | `auto` (default), `on`, `off` | Controls text normalization, for example, how numbers, times, and IDs are read out. Set it to `on` if long number sequences are mispronounced. |
| `apply_language_text_normalization` | `true`, `false` (default) | Turns on language-specific text normalization. |
| `voice_settings.stability` | 0 to 1 | How stable the voice is across generations. |
| `voice_settings.similarity_boost` | 0 to 1 | How closely the voice follows the original voice. |
| `voice_settings.style` | 0 to 1 | How strongly the voice exaggerates the speaking style. |
| `voice_settings.speed` | 0.7 to 1.2 | The speaking speed. |
| `voice_settings.use_speaker_boost` | `true`, `false` | Boosts the similarity to the original speaker. |
| `pronunciation_dictionary_locators` | Array of up to 3 objects with `pronunciation_dictionary_id` and an optional `version_id` | The pronunciation dictionaries to apply. |
| `seed` | Integer from 0 to 4294967295 | A seed that makes repeated requests with the same input more likely to return the same speech. |
| `previous_text` | String | The text that comes before the spoken text, to keep the speech consistent across requests. |
| `next_text` | String | The text that comes after the spoken text, to keep the speech consistent across requests. |
| `queryOptions.enable_logging` | `true` (default), `false` | Turns request logging at ElevenLabs on or off. |

Example:

```json
{
  "vendor": "elevenlabs",
  "options": {
    "apply_text_normalization": "on",
    "voice_settings": {
      "speed": 1.2
    }
  }
}
```

  </Accordion>

  <Accordion title="Google">

For details, see the [Google Cloud Text-to-Speech API](https://cloud.google.com/text-to-speech/docs/reference/rest/v1/text/synthesize).

| Field | Values | Description |
| ----- | ------ | ----------- |
| `audioConfig.speakingRate` | 0.25 to 2.0 | The speaking speed. |
| `audioConfig.pitch` | -20 to 20 | The pitch, in semitones. |
| `audioConfig.volumeGainDb` | -96 to 16 | The volume gain, in decibels. |
| `audioConfig.effectsProfileId` | Array of strings | The audio effects profiles to apply, for example, for a specific playback device. |
| `advancedVoiceOptions.lowLatencyJourneySynthesis` | `true`, `false` | Turns on low-latency synthesis for Journey voices. |

To select the voice and the gender, use `synthesizer.voice` and `synthesizer.gender`.

Example:

```json
{
  "vendor": "google",
  "options": {
    "audioConfig": {
      "speakingRate": 1.1,
      "pitch": -2
    }
  }
}
```

  </Accordion>

  <Accordion title="AWS">

For details, see the [Amazon Polly API](https://docs.aws.amazon.com/polly/latest/APIReference/API_SynthesizeSpeech.html).

| Field | Values | Description |
| ----- | ------ | ----------- |
| `LexiconNames` | Array of strings | The names of the pronunciation lexicons to apply. |

To select the engine and the language, use `synthesizer.engine` and `synthesizer.language`.

Example:

```json
{
  "vendor": "aws",
  "options": {
    "LexiconNames": ["my-lexicon"]
  }
}
```

  </Accordion>

  <Accordion title="Deepgram">

For details, see the [Deepgram text-to-speech API](https://developers.deepgram.com/reference/text-to-speech/speak-request).

| Field | Values | Description |
| ----- | ------ | ----------- |
| `queryOptions.speed` | 0.7 to 1.5 (default 1) | The speaking speed. |
| `queryOptions.callback` | String | The URL that Deepgram calls when the synthesis finishes. Applies only when TTS streaming is off. |
| `queryOptions.callback_method` | `POST` (default), `PUT` | The HTTP method for the callback. Applies only when TTS streaming is off. |
| `queryOptions.tag` | String or array of strings | Labels that identify the request in Deepgram usage reports. Applies only when TTS streaming is off. |

Example:

```json
{
  "vendor": "deepgram",
  "options": {
    "queryOptions": {
      "speed": 1.2
    }
  }
}
```

Microsoft, Speechmatics, and custom speech providers don't accept any options. For the supported speech providers, see [TTS and STT vendors](/voice-gateway/references/tts-and-stt-vendors).
